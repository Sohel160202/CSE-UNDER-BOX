# Capstone: Student Result Manager

## Goal

Build a command-line Student Result Manager in C.

## Required features

- Add a student with ID, name, and marks.
- Display all students.
- Search by ID.
- Calculate total, average, and grade.
- Show the highest scorer.
- Validate marks from 0 to 100.
- Use structures, arrays, functions, conditions, and loops.
- Handle an empty class safely.

## Suggested architecture

- Student data structure
- Input and validation functions
- Grade and calculation functions
- Search and reporting functions
- Menu loop
- Main function for high-level flow only

## Submission

- Problem statement
- Algorithm and flowchart
- Source code
- Test plan with at least ten cases
- Screenshots of sample runs
- Short reflection describing one bug and how it was fixed

## Evaluation

- Correctness: 40%
- Program design: 20%
- Input validation: 15%
- Testing and debugging evidence: 15%
- Readability and documentation: 10%
