# Loops and Repetition

## Objectives

- Choose between for, while, and do-while.
- Trace loop initialization, condition, body, and update.
- Avoid infinite loops and off-by-one errors.

## Explanation

A loop repeats a block while a condition remains true. A for loop is useful when the number of repetitions is clear. A while loop is useful when repetition depends on a condition. A do-while loop executes its body at least once.

## Example

    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        sum += i;
    }

## Trace

For each iteration, record i and sum. Tracing turns invisible execution into evidence.

## Practice

Write programs to calculate factorial, generate a multiplication table, test whether a number is prime, and find the greatest common divisor of two numbers.
